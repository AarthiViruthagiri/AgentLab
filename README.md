# AgentLab 🐍

**A Simple Python Project Exploring Different Types of Agents**

AgentLab is a beginner-friendly project built using basic Python programming. It demonstrates different agent concepts through simple logic, user input, conditional statements, and file handling.

## 📁 Project Structure

```text
AgentLab/
├── Approved_based_agent.py
├── Feedback_based_agent.py
├── feedback.json
├── human_in_the_loop.py
├── human_on_the_loop.py
├── human_out_of_the_loop.py
├── Reflection_agent.py
├── agent_log.jsonl
├── requirements.txt
└── README.md
```

## 🚀 Agents in This Project

- **Approved-Based Agent:** Demonstrates an agent workflow involving user approval.
- **Feedback-Based Agent:** Uses user feedback to adjust its responses.
- **Human-in-the-Loop Agent:** Includes human input in the decision-making process.
- **Human-on-the-Loop Agent:** Demonstrates human supervision of an agent's actions.
- **Human-out-of-the-Loop Agent:** Demonstrates actions performed without human approval at every step.
- **Reflection Agent:** Demonstrates basic response checking and self-evaluation.

## 🛠️ Technologies Used

- Python
- Basic conditional statements
- Functions and user input
- JSON file handling

## ▶️ How to Run

**1. Install Python 3** on your computer.

**2. Clone this repository:**

```bash
git clone https://github.com/YOUR-USERNAME/AgentLab.git
```

**3. Open the project folder:**

```bash
cd AgentLab
```

**4. Run any agent:**

```bash
python human_in_the_loop.py
```

You can replace the filename with any other Python agent in the project.
